AgentBoard

A native macOS command center for multiple terminal sessions

  • Run and monitor multiple terminal sessions in one window
  • Auto-detects AI agents (Claude, Codex, Gemini, Aider)
  • Live status badges — running, idle, needs attention
  • Sessions persist across app restarts
Download for macOS

Requires macOS 14+ (Sonoma) · Apple Silicon

First launch blocked by macOS?

AgentBoard is not signed with an Apple Developer certificate. To open it:

Right-click the app → Open → click Open in the dialog.

Or run: xattr -cr /Applications/AgentBoard.app
